## 3.2 Deskripsi Aktivitas

Berdasarkan analisis kebutuhan dari studi lapangan, penulis menggunakan metode **Waterfall** sebagai pendekatan pengembangan sistem. Metode ini dipilih karena kebutuhan sistem sudah terdefinisi dengan jelas dari hasil wawancara. Berikut adalah tahapan aktivitas yang dilakukan:

---

### 3.2.1 Communication

Pada tahapan pertama penulis akan melakukan pengumpulan data dengan cara berkomunikasi kepada pihak perusahaan untuk memahami permasalahan yang terjadi sehingga nantinya akan menghasilkan inisialisasi proyek dan dapat menciptakan tujuan yang diinginkan oleh pihak perusahaan.

**Aktivitas yang dilakukan:**

1. **Wawancara Stakeholder**: Melakukan wawancara dengan 4 narasumber yang memiliki peran berbeda dalam operasional distribusi LPG:
   - Kepala Operasional (manajemen dan pengambilan keputusan)
   - Petugas Gudang (pengelolaan stok fisik)
   - Sopir Agen (distribusi dan pengisian di SPBE)
   - Pangkalan (end-user yang memesan gas)

2. **Observasi Proses Bisnis**: Mengamati secara langsung alur kerja distribusi LPG dari SPBE → Agen → Pangkalan → Konsumen.

3. **Analisis Dokumen**: Meninjau dokumen-dokumen yang digunakan seperti buku pesanan, catatan Excel, dan nota pembayaran.

4. **Identifikasi Masalah**: Menyusun daftar permasalahan berdasarkan hasil wawancara dan observasi.

**Hasil Tahap Communication:**

| Aspek | Deskripsi |
|-------|-----------|
| **Stakeholder** | PT Mitra Surya Natasya (Agen LPG) |
| **Pengguna Sistem** | Admin/Operator, Petugas Gudang, Pangkalan |
| **Lingkup Sistem** | Manajemen pesanan, stok, keuangan, dan pelaporan |
| **Platform** | Aplikasi web yang dapat diakses dari browser |

---

### 3.2.2 Planning

Pada tahapan selanjutnya penulis membuat sebuah penjadwalan mengenai penelitian yang dilakukan sehingga mengetahui setiap proses yang sudah dikerjakan atau yang belum dikerjakan dan penulis membuat resiko-resiko yang dapat terjadi ketika memuat sistem tersebut.

**Aktivitas yang dilakukan:**

1. **Penyusunan Timeline Proyek**:

| Fase | Aktivitas | Durasi |
|------|-----------|--------|
| Analisis | Studi lapangan, wawancara, analisis kebutuhan | 2 minggu |
| Desain | Perancangan database, UI/UX, arsitektur sistem | 2 minggu |
| Implementasi | Pengembangan frontend dan backend | 6 minggu |
| Testing | Pengujian black-box dan UAT | 1 minggu |
| Deployment | Deployment ke server production | 1 minggu |

2. **Analisis Risiko**:

| Risiko | Dampak | Mitigasi |
|--------|--------|----------|
| Perubahan requirement | Jadwal mundur | Dokumentasi requirement yang detail |
| Integrasi API gagal | Fitur tidak berfungsi | Testing bertahap per modul |
| Data migrasi bermasalah | Data hilang/rusak | Backup berkala |
| User tidak familiar | Sistem tidak digunakan | Pelatihan dan dokumentasi |

3. **Alokasi Sumber Daya**:
   - 1 Developer Full-stack
   - Tools: VS Code, Git, Figma, Visual Paradigm
   - Infrastruktur: Vercel (frontend), Railway (backend + database)

---

### 3.2.3 Modeling

Pada tahapan selanjutnya penulis melakukan proses mencari suatu permasalahan, lalu mencari solusi dan menentukan solusi untuk menyelesaikan permasalahan yang ada dalam sebuah sistem, selanjutnya penulis akan membuat sebuah rancangan antarmuka yang nantinya akan diimplementasikan ke dalam program.

**Aktivitas yang dilakukan:**

1. **Pemodelan Data (Database Design)**:
   - Merancang Entity Relationship Diagram (ERD)
   - Mendefinisikan tabel-tabel utama: `users`, `pangkalans`, `orders`, `order_items`, `lpg_products`, `stock_history`, `payments`
   - Menentukan relasi antar tabel dan constraint

2. **Pemodelan Proses (UML Diagrams)**:
   - **Use Case Diagram**: Menggambarkan interaksi aktor dengan sistem
   - **Activity Diagram**: Menggambarkan alur proses bisnis
   - **Sequence Diagram**: Menggambarkan interaksi antar objek
   - **Class Diagram**: Menggambarkan struktur entity dan method

3. **Pemodelan Antarmuka (UI/UX Design)**:
   - Membuat wireframe menggunakan Balsamiq
   - Merancang design system (warna, typography, komponen)
   - Prototyping halaman-halaman utama

**Hasil Pemodelan:**

| Diagram | Keterangan |
|---------|------------|
| ERD | 15+ tabel dengan relasi lengkap |
| Use Case | 3 aktor (Admin, Operator, Pangkalan) dengan 20+ use case |
| Activity Diagram | 5 diagram untuk proses utama |
| Sequence Diagram | 5 diagram untuk interaksi sistem |
| Wireframe | 15+ halaman UI |

---

### 3.2.4 Construction

Pada tahapan selanjutnya penulis akan menerjemahkan apa yang ada dalam perancangan ke dalam kode. Yang dimana aplikasi yang akan dibangun berbasis web.

**Aktivitas yang dilakukan:**

1. **Setup Development Environment**:
   - Inisialisasi project dengan Astro + React (frontend)
   - Inisialisasi project dengan NestJS + TypeScript (backend)
   - Konfigurasi PostgreSQL database dengan Prisma ORM
   - Setup Git repository dan branching strategy

2. **Pengembangan Backend**:
   - Implementasi Authentication (JWT-based)
   - Implementasi CRUD untuk setiap modul
   - Integrasi Google Gemini AI untuk Voice Order
   - Implementasi role-based access control

3. **Pengembangan Frontend**:
   - Implementasi halaman Login dan Dashboard
   - Implementasi modul Pesanan (create, read, update status)
   - Implementasi modul Stok dengan monitoring real-time
   - Implementasi modul Keuangan dan Laporan
   - Implementasi Voice Order UI

4. **Integrasi dan Testing**:
   - Integrasi frontend dengan backend API
   - Black-box testing untuk setiap fitur
   - User Acceptance Testing (UAT)

**Teknologi yang Digunakan:**

| Layer | Teknologi |
|-------|-----------|
| Frontend | Astro, React, TypeScript, Tailwind CSS |
| Backend | NestJS, TypeScript, Prisma ORM |
| Database | PostgreSQL |
| AI | Google Gemini 2.0 Flash |
| Hosting | Vercel (frontend), Railway (backend + DB) |
| Version Control | Git + GitHub |

---

### 3.2.5 Deployment

Pada tahapan ini, penulis melakukan deployment aplikasi ke server production agar dapat diakses oleh pengguna secara online.

**Aktivitas yang dilakukan:**

1. **Konfigurasi Server**:
   - Setup PostgreSQL database di Railway
   - Konfigurasi environment variables
   - Setup SSL/HTTPS untuk keamanan

2. **Deployment Frontend**:
   - Build production bundle
   - Deploy ke Vercel dengan Git integration
   - Konfigurasi custom domain (opsional)

3. **Deployment Backend**:
   - Deploy NestJS API ke Railway
   - Konfigurasi database connection
   - Setup health checks dan monitoring

4. **Post-Deployment**:
   - Verifikasi semua fitur berjalan normal
   - Monitoring performa dan error
   - Dokumentasi untuk maintenance

**URL Deployment:**

| Komponen | URL |
|----------|-----|
| Frontend | https://sim4lon.vercel.app |
| Backend API | https://sim4lon-api.up.railway.app |
